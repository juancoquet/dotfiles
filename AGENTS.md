# Dotfiles — Agent Instructions

## Voice

- All agent-facing content authored here — skills, subagent definitions, and
  the canonical `configs/agents/AGENTS.md` — uses first and second person
  exclusively. First person ("I", "me", "my") refers to the user the agent interacts with; second person
  ("you", "your") is the agent being prompted. Never refer to the user in the
  third person as "the user, "he", or by name.

## Concision

- Write agent prompts to be concise but clear. Say what the agent must do in as
  few words as it takes to be unambiguous — no filler, no restating, no padding.
- Prefer plain, direct instructions over elaborate explanation. Add detail only
  where its absence would leave the agent guessing.
